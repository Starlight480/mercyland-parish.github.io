Database Setup & Admin Settings

Guide for Firebase Firestore database and admin security.

Firebase Firestore Database Rules

To ensure the Admin Portal can save data seamlessly, make sure your Firestore Security Rules in Firebase Console allow read and write:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
