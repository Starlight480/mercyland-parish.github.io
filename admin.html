Firebase Setup Guide

Follow these steps once to connect the admin portal to the live website database.

Step 1 — Create a Firebase Project

Go to console.firebase.google.com → Click "Add project" → Name it mercyland-parish → Click through to create it.

Step 2 — Enable Firestore Database

In your project, go to Build → Firestore Database → Click "Create database" → Select "Start in test mode" → Choose any region → Enable.

Step 3 — Register a Web App & Get Config

In your project dashboard, click the </> icon → Register app as mercyland-site → Copy the firebaseConfig object shown.

Step 4 — Paste Config into the Site

Open assets/js/firebase-init.js in the project folder → Replace the REPLACE_WITH_... placeholder values with your copied Firebase config → Save the file.

Step 5 — Push to GitHub

In your terminal: git add . && git commit -m "Add Firebase config" && git push
Your admin portal will then save directly to the live website!

Admin Passcode: The current default passcode is mercyland123. To change it, open admin.html and find the line if (code === "mercyland123") and replace it with your own secret word.
